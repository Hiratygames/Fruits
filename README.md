# 作品名：フルーツパーラー万疋屋
## ゲーム概要
専門学校の講師として授業でスイカゲームを作成し、そのアレンジとしてルールを追加したゲームです。<br>
落とした果物を食材として客のオーダー料理を提供していく、スイカゲーム＋レストラン経営のゲームです。<br>
オーダーを達成していくと店のランクが上がり、より高度なオーダーが発生してより大きな利益を得ることができます。<br>
## 開発期間
1か月（およそ20時間程度）
## 開発人数
1人
## 開発環境
Unity 6000.0.3f1
## 使用言語
C#
## 使用アセット
特になし
## 操作方法
決定・果物を落とす：Space<br>
料理提供：Enter<br>
オーダー切り替え：左右Shift<br>
メニューを開く：E<br>
## 実装範囲
Unityのチュートリアルや公開されているプロジェクトなどは使用せず、一から自分で実装しています。<br>
画像はCopilot、ChatGPTに作成してもらい、GIMPを用いて編集しました。<br>
BGM・SEはフリーのサイトでダウンロードしたものをプロジェクトに導入しました。<br>
## 工夫した点・特に見ていただきたいコード
### ・プログラム初学者に向けた簡易実装
ベースのスイカゲーム部分は、専門学校夜間1年生の授業で初学者向けとして設計したため、実装の容易さや説明のしやすさ等を重視しています。<br>
そのため、様々な制約がある状態での設計となっています。<br>
### ・旧Inputのラッピング
Assets/Scripts/PlayerInput.cs<br>
Nintendo Switch(デバッグ)とPCでのマルチプラットフォームで作成しているため、ラッピングして使用側で簡潔に記述できるように設計しました。<br>
今作ではSingletonパターンを使用し、static関数でアクセスできるようにすることで旧Inputに近い形で扱えるようにしています。<br>
また、アナログスティックの入力をAxisで取りつつDown,Press,Upのbool値でアクセスできるようにすることで、スティック入力をボタンのように扱えるよう工夫しています。<br>
